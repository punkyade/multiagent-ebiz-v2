# Harness v2 (ebiz)

[English](README.md) | **한국어**

요청 한 문장으로 에이전트 팀과 그 팀이 쓸 스킬을 만들어 주는 Claude Code 플러그인입니다.

## 설치

```shell
/plugin marketplace add punkyade/multiagent-ebiz-v2
/plugin install harness@ebiz-marketplace-atdge
```

## 사용

```
하네스 구성해줘
```

사용해 본 하네스를 개선할 때:

```
하네스 회고해줘
```

## 업데이트

```shell
/plugin update harness@ebiz-marketplace-atdge
```
