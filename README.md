# Harness v2 (ebiz)

**English** | [한국어](README_KO.md)

A Claude Code plugin that turns a one-sentence request into an agent team and the skills they use.

## Install

```shell
/plugin marketplace add punkyade/multiagent-ebiz-v2
/plugin install harness@ebiz-marketplace-atdge
```

## Use

```
build a harness for this project
하네스 구성해줘
```

To improve a harness after using it:

```
evolve the harness with this feedback
하네스 회고해줘
```

## Update

```shell
/plugin update harness@ebiz-marketplace-atdge
```
